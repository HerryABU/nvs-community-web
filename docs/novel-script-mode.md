# 话本气泡体（script mode）· 设计与实现

> 目标：给小说增加一种「对话驱动」的叙事形态（参照话本小说网），正文按角色分气泡呈现，
> 区别于传统散文体（prose）。同一部作品二选一，主笔可切换（`novels.mode`）。

---

## 1. 源文约定（作者怎么写）

存进章节文件的仍是**纯文本**，不引入新的存储格式（哈希/签名/导入导出链路全部复用）：

| 写法 | 解析结果 |
|---|---|
| `角色名：台词` | 对话气泡（角色名 ≤ 16 字，冒号支持 `：` 与 `:`） |
| 同一角色**连续多行** | 合并为同一个气泡内的多段（符合话本小说网观感） |
| `【场景/动作】` `（）` `[]` `()` 整行 | 舞台提示（居中斜体灰底） |
| 其余行 | 旁白（居中正文） |
| `旁白：` `旁述：` `画外音：` | 强制判为旁白，不当角色名 |
| 空行 | 分隔（不产生节点，同时打断同角色合并） |

误判防护：

- 角色名超过 16 字 → 不判为对话（长句带冒号，如说明文字）
- 行内出现 URL（`https://a:b`）时不会被当成角色（冒号前含空格且长度 > 6 时不认）
- 角色名含空格且长度 > 6 → 不认

## 2. 左右分侧

按角色**首次出现顺序**交替：`第 1、3、5… 个角色` 在左，`第 2、4、6… 个` 在右。
同一作品内角色顺序稳定（不随浏览者变化），旁白与舞台提示始终居中。

## 3. 渲染与安全

- 渲染在**服务端**完成：`server/scriptmode`，章节读取接口在 `mode=script` 时用气泡 HTML 覆盖
  `html_content`，前端不再二次解析（避免前后端两套逻辑漂移）。
- 所有文本统一 `html.EscapeString` 后再拼接，**不输出任何未经转义的用户内容**；
  段落内换行转义后替换为 `<br>`。
- 结构：`.script-chapter > .script-bubble.sb-left/.sb-right > .sb-avatar + .sb-body > .sb-name + .sb-text`，
  加上 `.script-stage`（舞台提示）与 `.script-narration`（旁白）。

## 4. 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/novels/:id/chapters/:num` | `novel_mode=script` 时 `html_content` 为气泡 HTML |
| POST | `/api/script-preview` | 编辑器实时预览：`{ content, novel_id }` → `{ html, speakers, lines, speaker_count }` |

> `/script-preview` 不能挂在 `/novels` 下——gin 的 httprouter 不允许静态段与 `/novels/:id` 同级通配共存。
> 传 `novel_id` 时服务端校验「主笔或平台角色」，避免被当成开放渲染服务滥用；单次预览上限 20000 字。

## 5. 前端落点

- `web/src/views/Reader.vue`：`script` 作品默认气泡视图，可切「原文」；气泡样式用 `:deep()` 写在阅读器内。
- `web/src/views/ChapterEditor.vue`：`script` 作品显示「话本气泡体」标签 + 「气泡预览」抽屉（实时调预览接口）。
- `web/src/views/Editor.vue`：作品表单新增「叙事形态」单选（散文体 / 话本气泡体），存 `novels.mode`。

## 6. 已补齐（v2）

1. **气泡内表情**：行内 `[笑]` 等标记渲染为表情字符（`server/scriptmode/emoji.go`，~40 个内置词）。
   只在**已转义文本**上替换，不认识的词原样保留；编辑器预览里可点击插入。
2. **气泡内图片**：整行 `![说明](图片地址)` 渲染为图片气泡；URL 走白名单
   （`http/https`、站内相对路径），`javascript:` / `data:` / `file:` 等一律拒绝，
   非法地址降级为提示文本而**不会**拼进 `src`（`server/scriptmode/media.go`）。
3. **章节级混排**：`chapters.mode`（空=继承作品 / `prose` / `script` / `mixed`）。
   `mixed` 下连续非对话行聚成散文块走 Markdown，与对话气泡同章共存（`ParseMixed`）。
4. **话本专用 AI 模板**：场景 `novel_script` 内置 4 个模板
   （话本续写 / 台词口吻校准 / 场景提示生成 / 对话去水检查），
   编辑器在话本形态下自动切到该场景。
