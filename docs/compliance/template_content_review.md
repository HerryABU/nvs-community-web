# 【站点名称】信息内容审核制度

> 依据《网络安全法》第四十七条、《网络信息内容生态治理规定》及公安部令第176号
> 第七条第八项（公共信息内容审核）制定。
> 版本：V1.0　编制：站点管理员　实施日期：【YYYY年MM月DD日】

## 一、适用范围

本制度适用于【站点名称】全部公共信息展示场景，包括但不限于：
小说正文、章节、评论、论坛帖子、博客文章、用户自定义HTML/扩展应用、
公告栏、头像与上传图片等。

## 二、禁止发布的内容（负面清单）

依据法律法规与公序良俗，以下内容一律禁止：

1. 危害国家安全、破坏国家统一、宣扬恐怖主义、极端主义的内容；
2. 煽动民族仇恨、破坏民族团结的内容；
3. 宣扬淫秽色情、暴力血腥、赌博的内容；
4. 诽谤、侮辱他人，侵犯他人名誉权、肖像权、隐私权的内容；
5. 侵犯他人著作权、商标权等知识产权的内容；
6. 宣扬封建迷信、邪教组织的内容；
7. 散布谣言、扰乱社会秩序的内容；
8. 法律、行政法规禁止的其他内容。

## 三、审核机制

### 3.1 审核方式

| 方式 | 说明 |
|------|------|
| 机器自动过滤 | 违禁词库（关键词/正则双模式）自动标记或拦截；XSS规则库拦截恶意代码 |
| 人工审核 | 高风险内容（被举报、被机器标记、新用户首次发布）进入人工复核队列 |
| 事后巡查 | 管理员定期巡查平台内容，发现违规立即处置 |

### 3.2 审核时效

- 举报内容：24小时内完成核查与处置；
- 机器标记待审内容：48小时内完成人工复核；
- 巡查发现违规：立即处置并留存证据。

## 四、处置措施

对违规内容视情节采取：删除/下架 → 屏蔽用户（禁言）→ 封禁账号 → 报告执法机关。

所有处置均留存记录（本平台软删除留证机制自动保存证据，可追溯）。

## 五、用户申诉

用户对被处置内容有异议的，可在处置后 7 日内向平台申诉（联系站长/管理员），
平台在 3 个工作日内复核并答复。
