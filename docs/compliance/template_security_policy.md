# 【站点名称】网络安全管理制度

> 依据《网络安全法》《数据安全法》《个人信息保护法》及公安部令第176号
> 《公安机关网络空间安全监督检查办法》制定。
> 版本：V1.0　编制：站点管理员　实施日期：【YYYY年MM月DD日】

## 一、总则

1. 本制度适用于【站点名称】（域名：【域名】）的网络安全管理活动。
2. 站点负责人（站长）为网络安全第一责任人，技术管理员负责日常安全运维。
3. 目标：保障平台业务连续运行，防止网络攻击、数据泄露、内容违法等事件发生。

## 二、组织与职责

| 角色 | 职责 |
|------|------|
| 站长（负责人） | 审批安全制度、重大变更；配合公安监督检查 |
| 技术管理员 | 安全配置、漏洞修复、日志留存、应急响应 |
| 内容审核员 | 落实信息内容审核制度（见独立制度文档） |
| 全体用户 | 遵守平台规则，不得利用平台从事违法活动 |

## 三、账号与访问控制

1. 管理员账号使用强密码（≥12位，含大小写/数字/符号），禁止共用账号。
2. 管理员账号开启登录失败锁定（连续失败5次锁定15分钟）。
3. 离职或岗位调整人员账号立即回收权限。
4. 用户注册信息（邮箱、IP等）按最小必要原则收集与留存。

## 四、系统与数据安全

1. 服务器部署最新安全补丁，重要服务配置防火墙，仅开放必要端口。
2. 数据库访问凭据加密存储（本平台存于 `data/secure-config.json`，密钥 0600 权限）。
3. 敏感信息（Token/密码等）在日志中自动脱敏（管理后台「日志脱敏」）。
4. 定期备份数据（本平台支持定时自动备份，建议每日）。
5. 对外服务应启用 HTTPS（可通过反向代理 nginx 配置证书）。

## 五、日志留存（176号令第三条）

1. 平台自动记录全量访问日志（含用户ID、IP、请求、响应），按小时切分、按天归档。
2. 日志留存期限：**不少于 6 个月**（本平台自动归档 gzip + SHA256 校验，保留6个月）。
3. 日志仅授权管理员可查，导出需登记用途。

## 六、漏洞与安全事件管理

1. 发现漏洞立即记录（管理后台「漏洞管理」），按严重程度限期整改：
   - 严重/高危：72小时内完成初步评估，7天内完成整改；
   - 中危：30天内完成整改；
   - 低危：90天内完成整改或记录为可接受风险。
2. 发现安全事件（入侵、数据泄露、篡改）时：先止损、再取证、后恢复，并按
   《应急响应预案》处置，必要时向属地公安网安部门报告。

## 七、监督检查配合

1. 配合公安机关依法开展的网络空间安全监督检查，如实提供备案、制度、日志、
   漏洞整改等材料。
2. 检查中发现的问题按要求限期整改，并留存整改记录。
