⚠️ 这个二进制没有嵌入前端产物

当前是用 -tags nodist 编译的「编译/测试轨」，只用于 go build ./... / go vet / go test 这类不产出发布物的场景， 不能当作可部署的发布物。

要得到能用的单文件，请按顺序：

  1. cd web && npm run build（产物落在项目根 dist/）
  2. 同步到 server/dist/（make dist 会做好这一步）
  3. cd server && go build -o nvs-server（**不要**带 -tags nodist）

API 仍然可用：/api/setup/status 等接口不受影响。
