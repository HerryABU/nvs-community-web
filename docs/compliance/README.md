# NVS 平台合规指引总览

> 本目录为 NVS 平台（去中心化网络小说平台）的合规制度文档模板，供站长依据
> 《网络安全法》《数据安全法》《个人信息保护法》及公安部令第176号
> 《公安机关网络空间安全监督检查办法》（2026年10月1日施行）的要求，
> **结合实际运营情况修改后**作为本单位书面制度使用。

## 使用说明

1. 下载/复制模板，将 `【占位】` 内容替换为站点实际信息（站点名称、负责人、联系方式等）；
2. 打印或另存为 PDF，加盖公章/负责人签字后归档；
3. 制度修订时保留历史版本，并记录修订人与时间（建议至少保留近 6 个月版本）；
4. 可在管理后台「合规制度」页面记录制度文件版本与更新时间。

## 相关法规速查

- **公安部令第176号**《公安机关网络空间安全监督检查办法》：2026年10月1日施行，
  将监管对象扩展至网络空间安全相关主体，重点检查 11 项内容。
- **《网络安全法》** 第二十一条：网络运营者应当按照网络安全等级保护制度的要求履行安全保护义务。
- **《数据安全法》**：数据分类分级保护、重要数据处理者的风险评估义务。
- **《个人信息保护法》**：个人信息处理的最小必要原则、告知同意规则。
