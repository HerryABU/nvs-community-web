### 部署与运维
- 🌍 **全平台全CPU支持** — Windows / Linux / macOS × x64 / ARM64 / ARM32(v6/v7) / RISC-V（10 个预编译目标；`windows/386`、`windows/arm`、`linux/mips64` 因依赖的纯 Go SQLite 实现没有对应架构的转译代码而不可用，这是依赖选型的固有限制，不是配置问题）
- 🚀 **下载即用** — 选择对应平台二进制文件，直接运行，零依赖安装（约 59–67 MB，含内嵌前端与 ip2region 离线库）
- ⚙️ **自动创建 .env** — 首次启动自动生成配置文件，自动检测本机 IPv4/IPv6 地址填入
- 🔌 **配置化绑定** — 支持配置 `BIND_IPV4` / `BIND_IPV6` / `ENABLE_IPV6`，灵活控制监听网卡
- 🌐 **启动时列出所有访问地址** — 扫描所有网卡，输出 `localhost` + 局域网 IP 的完整 URL 列表
- 🛡️ **Windows 防火墙自动配置** — 尝试自动添加 `netsh` 入站规则，管理员权限不足时输出命令行供复制
- 📦 **前端内嵌** — Vue 3 前端编译进 Go 二进制，单文件部署
- 🗄️ **SQLite 零配置** — 首次运行时自动创建数据库，无需安装或配置
- 🧭 **建站向导** — 首次运行进入可视化安装向导（环境检查 / 数据库连通测试 / 站点名与管理员设置），一次性安装密钥仅控制台显示一次
- 🔐 **数据库配置加密** — 数据库连接信息（含密码）经 AES-256-GCM 加密落盘 `secure-config.json`，不写明文 `.env`
- 🔄 **数据库在线热迁移** — SQLite ↔ MySQL 双向热切换，全程无需重启，逐表复制并上报进度
- 💾 **备份 / 恢复 / 定时备份** — SQLite `VACUUM INTO` 无损快照 / MySQL 全表 JSON 快照，支持按间隔定时调度
- 🔀 **站点路径前缀挂载（反向代理）** — 通过 `URL_PREFIX`（如 `/go-nvs`）将整站挂到任意子路径（`http://网关:8088/go-nvs/login`），供 nginx / 自建网关等反向代理使用；前端**自动感知前缀**（Vue Router base / axios baseURL / 资源绝对前缀 / 跳转），支持「保留前缀」「去前缀」两种转发模式，**前缀名任意配置、严禁硬编码**；反向代理仅改写 `<base href>` 时前端自动从 `document.baseURI` 推导实际挂载前缀
- ⚡ **静态资源强缓存** — Vite 产物 `assets/*`（文件名即内容指纹）→ `Cache-Control: immutable` 一年；`index.html` → `no-cache` 每次重新验证，发布新版本后浏览器立即拿到，杜绝重复全量下载 js/css
- 🏷️ **页脚开源署名** — 参考 alist「Powered by」风格，站底常驻「由 **NVS** 驱动 vX.Y.Z」并链接 GitHub 仓库（`HerryABU/nvs-community-web`），与 ICP/公安备案号同排展示；版本号统一管理（Go `version` 包 + 前端 `package.json` + README 顶部徽章，`/api/setup/status`、建站向导、健康页、启动日志同步一致）

### 用户系统
- 🔐 **JWT HttpOnly Cookie 认证** — `SameSite=Lax`，72h 过期
- 🔑 **bcrypt 密码哈希**
- 📧 **邮箱验证码** — 支持 QQ邮箱/Gmail/163 SMTP，6位数字验证码，10分钟有效
- 🧩 **滑块验证码** — `ENABLE_CAPTCHA` 开关控制
- 👥 **用户分级** — 普通用户（reader）/ 作者（author）/ VIP作者（vip_author）/ **警方（police）** / 仲裁员（arbitrator）/ 管理员（admin）；其中 **警方不可自注册**，只能由管理员在「用户管理 → 更多」提权，撤销/提权均写审计留痕
- 🪪 **个人中心统一入口** — 头像下拉只保留 5 项（个人中心 / 我的主页 / 管理员面板 / 警方取管台 / 退出登录）；更换头像、账号设置、钱包、API Key、私信、黑名单、特别关注、举报、模板设置、文档等 **14 个入口全部收进 `/me` 的「我的服务」**，按「账号与资料 / 互动与关注 / 资产与开放能力 / 外观与帮助」四组归类
- 📍 **注册/登录 IP 留存** — 记录 `registration_ip` / `last_login_ip` / `last_login_at`（176号令合规）
- 🕵️ **用户行为审计日志** — 登录成功/失败、登出、改密、注册全记录（含 IP / User-Agent）

### 作品创作
- 📝 **12 大分类** — 硬科幻 / 奇幻 / 推演文学 / 架空历史 / 现实主义 / 悬疑推理 / 实验文学 / 二次元 / 二次元同人 / 政治区 / 讽刺文学 / 其他
- 🎨 **Cherry Markdown 编辑器（0.11.9 完整版）** — 统一渲染引擎（编辑器 = 阅读器 100% 同源），支持 Markdown / KaTeX 公式（含 physics 物理宏包 + mhchem 化学式）/ Mermaid 图表 / chemfig 化学结构图（SMILES）/ 颜色标记 · 一键切换富文本模式；阅读器 / 博客 / 评论 / 论坛浏览端与编辑器预览共用同一 Cherry 主题样式，章节标题以大字显示（h1 2em 居中，h1-h6 全阶统一）
- 📂 **文件系统存储** — 小说正文以 HTML 存于文件系统，数据库仅存路径索引
- 🔗 **内容可验证** — 每章自动计算 SHA256 哈希 + HMAC-SHA256 作者签名，前端可验证章节完整性
- 📤 **多格式导出** — ZIP / Markdown / EPUB / TXT 一键导出
- 📥 **多格式导入** — 支持 ZIP / Markdown / TXT 导入，自动解析章节结构，支持预览确认
- 📦 **批量导入** — 小说批量导入支持三种模式：**一个文件一章**（标题取文件名，默认）/ 自定义正则拆分（快捷规则：第X章 / Markdown 标题 / 分割线）/ 自动识别标题；可选项「章节标题加第N章前缀」；**编辑模式下导入/批量导入自动追加到当前作品末尾，不会新建书本**（单文件导入同样支持追加）；**博客批量导入**：多文件一键创建多篇博客
- 📖 **四种叙事形态（散文 / 话本气泡 / 漫画体 / 图片模式）** — `Novel.Mode` / `Chapter.Mode` 枚举扩展为 prose / script / comic / image：散文即 Markdown 正文；话本气泡为角色对白体；**漫画体**逐页翻看，阅读器按页渲染；**图片模式**流览有序图集（每章 `Images` JSON 列存 `[{url,caption}]`）。形态按章节生效，`normalizeChapterImages` 校验并规范化图集（非法回落 `[]`），图片形态正文可空、以图集为准，章节编辑器在图片形态下以图集编辑器（上传/排序/图注/删除）替代文字编辑器
- 📊 **每篇内容统计（阅读 / 点赞 / 收藏）** — 作者仪表盘 `GetAuthorDashboard` 返回 per-content 列表：`novel_stats`（含 `view_count` / `like_count` / `favorite_count` 书架数）与 `blog_stats`（含 `view_count` / `like_count` / `favorite_count`）。小说点赞独立 `novel_likes` 表（`ToggleNovelLike` / `UserLikedNovel` + 接口 `/api/novels/:id/like`、`/api/novels/:id/likes`），小说收藏复用 bookshelf 统计不另建列；博客收藏独立 `blog_favorites` 表（`ToggleBlogFavorite` / `UserFavoritedBlog` + 接口 `/api/blogs/:id/favorite`、`/api/blogs/:id/favorites`）。前端 `AuthorStatsView` 以双表展示每篇内容的阅读/点赞/收藏并可跳转详情

### 🤖 AI 工作台（对话 / 绘画 / 视频 / 智能体）

> 默认**关闭**（`ai_enabled=false`）—— 未开启时入口仍可见并标注「未开启」，管理员可就地开启并配置模型池。

- 🧭 **竖列式入口**（184px 左导航 + 56px 顶栏）：AI 对话 / 大模型广场 / 专业绘画 / 视频创作 / 灵感广场 / AI 智能体 / 思维导图 / 会员与额度，**打开即落地对话页**（不做九宫格门户）
- 💬 **标准对话页**：空态大标题 + 推荐词卡；圆角自适应输入框（聚焦描边）+ 行内「厂商/模型/长度」+ 圆形发送/停止；历史会话、代码块工具条（见下）、**真正的重新生成**（先分支再重发，不会一问多答）
- 🧑‍💻 **代码块：高亮 · 复制 · HTML 预览 · 一键发布**（AI 回复与分享页均支持）：
  · 右上角工具条：语言标签 + 复制 —— 复制出来是纯代码，不会掺进按钮文字；
  · 语法高亮覆盖 36 种常用语言（JS/TS/Python/Go/Rust/Java/SQL/Bash/YAML/HTML…），按需加载，不影响首屏；
  · **预览**：HTML 片段与完整页面都能直接运行。沙箱隔离 —— 读不到本站 Cookie / localStorage，
    也无法跳转或改写本页面；可切「预览 / 源码」、重载、下载 `.html`。沙箱内提供内存版 Storage，
    AI 生成的小游戏、待办这类会写 localStorage 的页面不会因权限报错而白屏（刷新即重置）；
  · **发布**：一键发到 HTML 应用广场，走平台既有的安全预检与人工复核流程；
  · 代码块没写语言标注时，也会判断内容是否像 HTML，照样给出预览 / 发布入口。
- 🧠 **思考型模型**（DeepSeek-R1 / GLM / Qwen thinking）—— 上游把正文放在 `reasoning` / `reasoning_content` 字段，两种命名都识别；推理过程进「思考过程」折叠块、正文不重复推送，`answer_in_reasoning` 时自动落正文
- 🎨 **专业绘画**：左 320 参数栏 + 右纵向作品流（每任务一卡：模型/时间/提示词/图片栅格/参考图数），**不自建「本次结果」区块**（结果就是流里最新一项）
- 🎬 **视频创作**：与绘画页同构；进行中有状态条（排队/生成 + 自动刷新），支持**停止等待（取消 + 原路退款）**与**失败重新提交**；刷新页面自动恢复轮询；终态判定统一走 `IsAiMediaTerminal`（含 `cancelled`）
- 🧩 **智能体 / 思维导图 / 灵感广场 / 提示词库**：智能体卡片墙、mindmap 面板、灵感广场（图文/视频）、提示词模板一键填入
- 🎛 **模型池与路由**：多厂商协议（OpenAI 兼容 / Anthropic / Gemini / MJ / Kling / Coze…）、密钥池轮询与失败熔断、**路由策略**（最便宜/最快/按场景）+ 故障自动降级、成本闸门与按次计费、`thinking` 标记、15 个开箱预设（`base_url` 为空的预设必须先填中转地址）
- 🗂 **模型池两级导航**（参数用 `?tab=&view=`，可前进后退、可直接分享）：一级【模型配置 / 模型统计 / 路由与定价】，二级各按【自由添加 · 按渠道 · 按模型 · 按厂商】切换，二级按钮带实时计数
- 🔌 **填渠道即可拉模型 + 联通测试**：先填上游地址与密钥 →「拉取模型」列出该渠道全部可用模型（勾选导入、可设对用户可见）→ 联通性探针走 `GET /models` 不烧额度；模型名支持**四段式拆解**（模型大名 / 版本 / 类型 / 子号，如 `deepseek-v4.1-flash-1017` → `deepseek` / `v4.1` / `flash` / `1017`），列可按需显示/隐藏
- 💰 **渠道余额与真实成本**：按渠道（`base_url`）聚合，一条渠道只查一次（多模型共用同一账户余额）。余额来源分四种**显式**方式，不靠域名猜：`deepseek`（官方 `/user/balance`，模型 Key 即可）/ `newapi`（中转站 `nap_` 系统访问令牌 + 用户 ID → `/api/user/self`，`quota÷500000`）/ `custom`（站长自填 URL + 字段路径 + 除数×乘数，陌生渠道兜底）/ `none`（明确不查）
- 🧮 **虚拟代币 ≠ 真金白银**：中转站的「美元」只是站内代币，站长可填充值比例（`100 CNY = 1000 虚拟美元`，支持小数），界面同时显示「虚拟值 + 实（真实货币）」；**未设比例就不换算**，绝不显示看着精确其实假的金额；渠道级比例优先于全局
- 📈 **模型统计三个维度**：同一份调用日志按【渠道 / 模型 / 厂商】聚合调用次数、成功/失败、成功率、tokens 入出、实扣代币、平均延迟（按成功调用加权，失败不拉低均值）；模型被删后其历史调用仍计入，用量不会凭空消失
- 🔑 **BYOK**：用户可绑定自己的模型 Key（加密存储，仅本人可用），不占站内额度
- 🧾 **单次请求消耗双口径**：金额用「余额采样差值 ÷ 窗口内请求数」估算（后台每 10 分钟采样、保留 30 天），token 取自本站调用日志为**真实值**；中转站可另取 `/api/log/self` 的 `quota` 得到**精确**单次扣费（需系统令牌含「查看日志」权限，无权限时显示「无日志权限」而非假数据）
- 🏷️ **AIGC 内容标识（GB 45438—2025 / 标识办法）** —— AI 图片的**两层标识由服务端统一完成**，前端不碰像素：
  原图原封不动落盘（不带任何标识），用户点下载时走 `POST /api/ai/aigc/export`，
  Go 端按参数 `裁剪 → 缩放 → 烧角标 → 编码 → 写 AIGC 字段 → 返回二进制`。所以没有「原图直链」这条路可绕。
  · **显式**：角标文案/位置/颜色可配（默认「AI生成」），字号 = 最短边 × 5%（≥国标下限，低于自动抬到 5%），
    先深色描边再压浅色正文，浅底图上也看得见；
  · **隐式**：XMP 里写国标**七字段**（`Label=1`、`ContentProducer`、`ProduceID`、`ReservedCode1` 摘要 +
    传播侧三个留空），重复导出走幂等检查只保留一份；JPEG 写 APP1、PNG 写 iTXt，标准库实现、零 CGO；
  · **模型名绝不进法定字段**：默认只落本站数据库（`ProduceID → 模型名`），用 ProduceID 回查；
    站长坚持随文件传播时才写进 `ReservedCode1` 的 `h=…;m=…` 复合段（扩展用法，传播平台不保证解析）；
  · **显式标识豁免**（默认关闭）：开启后须逐字手输确认语句，只免角标、**隐式字段照写**，
    日志独立成表（手输原文 + SHA-256 + 协议版本 + 结果，留存 ≥180 天，不与隔离墙记录混用）；
  · 后台「合规与安全 → AIGC 内容标识」：配置 + 导出记录 + 豁免日志 + 用 ProduceID 一键核验；
    角标字体内置 Noto Sans SC 子集（SIL OFL 1.1，约 12 KB），可上传自有 `.ttf` 覆盖。
- 🧑‍💼 **智能体投稿 + 站长审核**：用户可投稿「特殊提示词模板」，站长三个开关（是否开放投稿 / 是否需要审核 / 每人待审上限防刷）；通过即上架广场并记录作者，拒绝必须写原因（用户据此改稿），改稿重审更新原条目而非新建；广场点一个直接进对话（**对话页不再有角色下拉**）
- 🧩 **左栏自定义菜单（站长配置）**：可挂**站内已有面板**或**任意 URL**（站长录入故不走 URL 白名单审核，但仍拦截 `javascript:` / `data:` 等伪协议防站点 XSS），支持分组、新标签打开、上下排序与显示开关

### 📖 阅读体验（精读 · 朗读 · 评论）

- 🔤 **阅读器**：字号三档（小/中/大，`localStorage` 记忆）、顶部 2px 阅读进度条、目录抽屉、上/下一章、书签与阅读进度同步书架
- ✍️ **划线批注**：选中正文 → 浮动按钮 → 写批注（`reading_notes.type=annotation`），本章划线面板可列出「我的 + 他人公开」批注，点击定位并闪烁；同一句多处出现按次序落位，不会互相覆盖；支持「仅自己可见」
- 🔊 **语音朗读**：服务端合成（`POST /api/ai/speech`），按句切段（≤1800 字/段、单次 ≤8 段）顺序播放，可随时停止，离开页面自动释放音频；未配置 audio 模型时给出明确提示而非静默
- 💬 **楼层式评论区**（公众号评论区 + Discuz 楼中楼）：回复主内容 = 开新楼（`floor_no` 递增），回复楼内某条 = 挂靠该楼并显示「X 回复 Y」可折叠
- 🔃 **评论排序**：`new`（最新楼在前，默认）/ `old`（最早在前，追更补读）/ `hot`（楼内回复多的在前，排除已删除回复）；排序只影响「楼」的顺序，**楼内回复恒按时间正序**
- 🎚 **评论密度**：紧凑 / 舒适一键切换（`localStorage` 记忆），四态齐全（骨架 / 空态引导 / 错误重试 / 内容）
- 🕸 **评论网（社交图谱）**：按「谁回复了谁」构建力导向图，识别互刷、抱团与孤岛
- 🔒 **加密楼**：楼可设访问密码（入口限制，内容不加密存储），未解锁者只见占位；
  凭 `X-Floor-Password` 头解锁，警方/管理员豁免。
  **楼加密 ≠ 评论区加密** —— 楼内回复（评论区）是否随楼一起被藏，由站长在
  「站点配置 → 评论区策略」里选：默认只锁楼正文（评论区照常可见，因为加密的是
  「我这一条说了什么」而不是「大家聊了什么」）；也可切回「整块对话对外不可见」。
  另可单独决定是否允许对未解锁的楼回复（默认不允许，避免盲回）。

### 安全与合规
- 🧱 **敏感区三级隔离墙** — 系统级（管理员配置敏感分区）+ 论坛级（敏感论坛自动触发）+ 作者级（自定义警告语），3~5步确认弹窗含手动输入，动态配置步骤数/警告语/跨域额外步数

  · 密钥由站长在**后台「运营 → 地图服务」**自行填写（内置申请步骤 + **一键检测**：浏览器实测两张瓦片 + 服务端 HTTP 诊断 + 天地图原文），也可用 `TIANDITU_TK` 环境变量注入。
**境外访客只给「全球」视野**：中国的省级/城市级读者分布不对境外开放（内网与保留地址按境内处理，
方便站内自测）。同时给出「境内 / 境外 / 内网」三口径占比，内网单列避免本机调试流量污染结论
- 🚨 **警方取管台（police 角色）** — 只看取证相关：软删除留证全量查看（按类型筛选 + 关键词 + 分页）、单条凭证下载、**全量取证包导出（二次确认并写明含个人信息、仅限依法调取）**、论坛巡查（含隐藏/加密/已删除）；**无**普通管理权，角色只能由管理员提权
- 🧯 **AI 内容可追溯** — 章节/博客记录「AI 参与」标记与生成模型名，评论可 @ai 召唤助手（配额可控、每日上限可关）
- 🛡️ **AI 安全闸（三层 + 跨轮拼装链）** — 对话入口四道闸门：
  · **规则引擎**（确定性）：管制物质 + 意图 + 工艺 + 参数的组合信号，外加**跨轮拼装合成链检测**
    （同一合成家族出现多个成员、含管制物质成员、且当前轮在问「怎么做」⇒ 判定为拼装攻击）；
  · **蓝队判定模型**：整段对话送审，识别 ADRO 阶梯（锚定→拆解→循环→输出），批次制调用以控成本；
  · **输出闸门**：增量扫描模型输出，判定「拒绝后泄漏」（拒绝语 + 试剂/工艺/参数方向）、
    **反应方程式硬信号**（给出方程式 = 合成步骤骨架已成形）、同族多物质同现；
  · **用户风险画像**：该账号索取危险品的累积程度达阈值 → 观察期（阈值收紧）→ 冷却（暂停 AI 功能）。
  · 话题判定按**整段对话**算 —— 管制物质只提一次、后面几轮不再点名的形态下，输出闸门仍保持武装。
- 🕊️ **绥靖模式（以疏代堵）** — AI 安全闸的第四种终止模式（`appease`）：
  · **用户完全无感**：不透拦截、不透终止、不进冷却；危险内容被改写为引导内容
    （科普 / 法律后果 / 求助渠道），看起来就是一次正常回答；
  · **独立响应路径**：拦截分支会下发 `blocked / terminated / replace` 并触发前端警告 toast，
    绥靖另走一条只下发 `content` / `done` 的分支 —— 用户消息与助手消息都按普通消息落库；
  · **提示词放松**：绥靖下主模型改用宽松安全准则（去掉常规模式「凡事预设可疑」的框架），
    显著降低对正常创作的误伤，准则可由管理员自定义；
  · **静默入档**：行为记入「可疑名单」，监管模型判定分越线自动升级「恶意名单」；
    人工改档（含降级）/ 清除 / 加注全部留痕。
- 📛 **名单子系统与一键取证** — 可疑 / 恶意两级名单，只存**证据引用**（正文按 TTL 过期）；
  一键导出取证包（名单记录 + 会话 + 消息 + 判定日志 + 逐文件 SHA256 完整性清单）；
  **警方须先申请、站长批准**后方可导出指定用户的取证包，未获批直接导出返回 403 并记审计。
- 🖼️ **评论图片多模态审核与留证** — 评论可携带图片（多模态送审）；违规图片**不落库**，
  按「拦截 + 留证」处理：软删除（deleted_by=ai_moderation）+ 审核日志 + 审计日志三件套齐写；
  图片来源仅接受站内 `/uploads/images/` 前缀，拒绝外链 / 数据 URL / 路径穿越。
- 🎨 **AI 绘画审核（两层）** —
  · **提示词初审（生成前，默认开）**：放在扣费与调上游之前，坏图根本没生成出来。
    规则只看三类几乎不可能出现在正常创作里的词（明确裸露 / 明确真实人物 / 明确制作爆炸物毒品），
    刻意不收「暴力/血/战争/恐怖」这类词 —— 绘画提示词天然大量出现它们；
  · **出图后审（生成后，默认关，可选）**：防「提示词看不出问题但模型画出了违规内容」。
    多模态判定，图片用 data URL 内联送审（图床 URL 常带临时签名，判定网关未必能取到）；
    判定违规则不返回图片并**自动退款**；审核调用失败按「失败时放行」开关处置。
- 🎛️ **作者工作台 · 独立视图（?tab=）** — 创作数据大屏原先把「收视率图 / 作品 / 博客 / 自定义 HTML /
  API Key / 论坛 / 回收站 / 封禁」全堆在一页，既拥挤又要并发打 8 个接口。现拆成六个独立视图，
  顶部切换栏切换，**当前视图写进 URL 的 `?tab=`**（可分享、可刷新保持、前进后退可用）：
  `stats`（数据与收视率，默认）/ `novels` / `blogs` / `html` / `keys` / `content`（论坛与回收站）。
  每个面板 lazy 挂载 —— 一屏只装一个视图，只在切到时才拉自己的数据。
- ⏱️ **自定义主题 JS 延迟加载（alist 语义）** — 站点主题与个人主题的自定义 JS 都可选择加载方式：
  **立即加载**（默认，与 alist 一致）/ **空闲时加载**（首屏 `window load` 后 `requestIdleCallback` 注入，
  不与首屏渲染抢主线程）/ **延时加载**（延迟 N 秒，默认 3、上限 600，适合埋点、统计、第三方挂件）。
- ✨ **绘画提示词优化** — 把简短描述扩写成信息密度更高的提示词（补光线/镜头/材质/氛围/构图）。
  三条边界写进系统提示词：绝不改变创作意图、绝不删除用户已有限定词、只补全不添加冲突元素；
  优化前后各过一次初审，不让「优化」成为绕过审核的旁路。

### 📦 自定义 HTML 托管（扩展应用）

上传 ZIP 包将完整的 HTML 应用部署到 NVS 平台，在独立沙盒中运行。支持任意前端技术栈（Vue/React/原生 JS），可包含 WASM 模块。

**上传流程**

```
编写应用（HTML+CSS+JS+WASM）→ 打包 ZIP → 上传到扩展应用 → 自动解压+安全扫描 → 沙盒运行
```

**ZIP 包规范**

| 限制项 | 值 |
|--------|-----|
| 压缩包大小 | ≤ 20 MB |
| 解压后总大小 | ≤ 50 MB |
| 压缩比 | ≤ 100:1（防 ZIP 炸弹） |
| 文件数量 | ≤ 500 |
| 允许扩展名 | .html .css .js .wasm .json .png .jpg .svg .woff2 等 |
| 入口文件 | 默认 index.html，可手动选择 |

**运行方式**

| 方式 | 路径 | 说明 |
|------|------|------|
| 完整运行 | `/app/:id` | 全屏沙盒，虚拟路径隐藏真实存储 |
| 弹窗预览 | 卡片「预览」按钮 | 对话框内 iframe 预览 |
| 广场运行 | 广场卡片点击 | 新标签页全屏运行 |

**HTML 应用广场**

作者设置项目为「公开」后，项目出现在广场 Tab 中。上传 ZIP 时自动提取首张图片作为缩略图。作者可设置「允许下载」，访客可下载原始 ZIP 包。

**端口代理**

扩展应用可分配独立端口（49152-65535 高位优先），通过命名路径 `/sandbox/proxy/{作者ID}/{项目名}/` 反向代理访问，端口号不在 URL 中暴露。

**虚拟文件系统 (VFS)**

沙盒应用可通过 REST API 在内存中读写数据，完全隔离于真实文件系统：

| 方法 | 端点 | 说明 |
|------|------|------|
| POST | `/api/sandbox-vfs/:id/write` | 写入 `{key, value}`，单值≤1MB，总量≤10MB/100键 |
| GET | `/api/sandbox-vfs/:id/read?key=` | 读取键值 |
| GET | `/api/sandbox-vfs/:id/list` | 列出所有键 |

**多层安全防护**

1. **上传前** — 23条内容安全扫描（提权命令/Shell注入/木马/挖矿/僵尸网络/数据窃取/钓鱼）
2. **解压中** — ZIP 炸弹检测（压缩比+总大小+文件数+路径穿越）
3. **解压后** — 目录锁定（文件→0444只读，目录→0755可写）
4. **运行时** — 写入拦截中间件（允许数据文件，禁止脚本文件）
5. **通信** — CSP + iframe sandbox 双重隔离
6. **路径隐藏** — `/app/:id` 虚拟路径，沙盒内无法探测真实存储位置

**WASM 支持**

- 上传时勾选「允许 WASM」
- 系统自动设置 `Cross-Origin-Embedder-Policy: require-corp`（启用 SharedArrayBuffer）
- 自动设置 `Cross-Origin-Opener-Policy: same-origin`
- CSP 启用 `'wasm-unsafe-eval'`
- `.wasm` 文件返回正确的 `Content-Type: application/wasm`

**展开/收起控件**

Markdown/富文本编辑器支持 `[expand title="标题"]...[/expand]` 语法，渲染为可点击展开的 `<details>` 折叠块。
