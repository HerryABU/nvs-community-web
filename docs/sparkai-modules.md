## 0. 全局框架（所有模块共用）

- 左侧竖排主导航：`AI 对话` / `大模型` / `专业绘画`(最新) / `灵感广场`(HOT) / `视频创作`(最热) / `AI智能体`→`Agent应用` / `思维导图` / `会员中心`→`查看更多` / `自定义应用`→`添加菜单` / `关于我们`
- 顶栏：`会员套餐` · `系统更新日志 v7.0.1`(带「新」角标) · `积分余额` · `登录`
- 全局入口：`开启新对话 Ctrl+K`
- 布局：左 200~240px 固定导航 + 右侧主区（主区顶部再放模块内 Tab）

## 1. AI 对话 / 大模型广场（chatai）

- 标题 + 计数：`大模型广场 140`
- 三级筛选：类型 Tab `全部/对话/图像/视频/音频/我的` → 厂商下拉 `全部厂商` → 搜索 `搜索模型 / 描述`
- 分组标题：`通用大模型（文本/图像）`（按厂商/能力分组）
- 卡片：`名称（🔥最新/🎨最强 前缀）` + `NEW` + `N 积分` + `厂商` + 2 句描述
- 右侧/侧栏：`对话历史 N`、`沉浸模式`
- 空态：`试试这样问` + 3 条示例 + 一排智能体快捷入口
- 输入区：`来说点什么吧...（Shift+Enter 换行 / Enter 发送）`、附件 `file`

## 2. 专业绘画（painting）

- 顶部三 Tab：`文生图 / 混图 / 换脸`（换脸标注维护中）
- 公告条：新版本能力说明（GPT-Image-2 4K、Nano Banana 全功能）+ 免费额度引导 + 违规警告
- 模型选择卡（横向四宫格）：`GPT-Image-2（OpenAI 多模态生图）` / `Nano Banana 2（谷歌新一代生图）` / `Midjourney（真实风格）` / `Niji（动漫风格）` + `更多绘画大模型`
- 二级参数：`模型版本`（高分辨率 PRO / 自动画质 DEV）、`分辨率`、`比例`（1:1 头像 / 9:16 竖版海报 / 2:3 手机壁纸 / 3:4 社交媒体 / 4:3 …）
- 交互范式：**模型 = 卡片墙（带一句定位说明）**，而不是下拉框

## 3. 灵感广场（market）

- 顶部 Content Tab：`图像 / AI视频`
- 风格分类（多行 chips）：图像侧 `全部/写实摄影/电商设计/画面控制/动漫游戏/插画设计/建筑空间设计`；视频侧 `真人写实/二次元/男生/真人/动漫二次元/插画/国风/海报设计/建筑空间/其他`
- 卡片：作品预览 + 模型徽标（`GEMINI-NANO-BANANA-2.1` / `GPT-IMAGE-2` / `MJ` / `NANO-BANANA-PRO`）+ 完整提示词正文 + `复刻同款` 按钮
- 价值点：**每条作品=可复用提示词**，一键复刻 → 直接填充到绘画/视频

## 4. 视频创作（video）

- 顶部 Tab：`我的创作 / 视频广场 / 公告`
- 卡片：封面 + 模型徽标（如 `Seedance 2.5`）+ 时长徽标（`79.6s`）+ 标题 + 完整分镜脚本（场景一/场景二…）
- 特点：**视频提示词按「分镜脚本」组织**（场景 + 人物 + 台词 + 镜头/画风），而非一句话

## 5. AI 智能体 / Agent 应用（agent / app-store）

- Agent 落地页：`用 Agent 重塑生产力` + 三个数据牌（`15+ 可用智能体` / `24/7 在线服务` / `∞ 无限可能`）+ 三条价值点 + 场景四宫格（内容创作/编程开发/语言翻译/数据分析）+ `快速开始(发现Agent智能体)`
- 应用市场：搜索 `搜索应用名称、快速查找应用...` + 分类（`全部分类/实用工具/文案创作/绘画工具/编程开发/在线翻译/教育学习/健康生活/论文工具/休闲娱乐/职业创作`）
- 卡片：图标 + 名称 + `@作者`（`@系统`=预设 / `@用户`=分享）+ 描述 + 使用量（`965 使用` / `8.4w+`）+ 标签（`预设应用`/`分享应用`/`GPTs应用`）

## 6. 思维导图（mind）

- 左：`您的需求？` 输入框（`请输入您想要生成内容的简单描述...`）+ `智能生成思维导图` + `试试示例`
- 右：Markdown 大纲预览（`# 🚀SparkAi 系统…` → `## 模块` → `- 能力点`），可转导图
- 本质：**LLM 产出层级大纲 → 前端渲染为导图**，无需独立图数据库

## 7. 会员中心 / 支付（pay / 页面1）

- 促销文案条 + 三类 Tab：`会员限时套餐 / 叠加永久次卡 / 天卡体验套餐`
- 套餐卡结构：套餐名 + 描述 + 价格（`￥6.00`）+ **分品类积分明细**（基础模型额度 / 高级模型额度 / 专业绘画额度 / Agent 积分额度）+ 有效期（1 天 / 7 天 / 30 天）
- 关键设计：**额度按能力分账**（普通模型 / 旗舰模型 / 绘画 / Agent），而非单一积分池
- 档位梯度：天卡 ¥6 → 周卡 ¥12 → 月卡 ¥38 → Agent 月卡 ¥39 → 季卡 …

## 8. 个人中心（user-center）

- 头部：头像 + `更换头像` + 昵称 + 邮箱 + 简介 + `编辑信息` + `退出登录`
- `当前权益`：`用户积分余额` + 分账明细（基础模型 / 高级模型=10 / 专业绘画=5 / Agent）+ 每类一句话说明
- `我的成就`：四类使用量统计（基础模型使用/高级模型使用/专业绘画使用/Agent 积分使用）+ `Token`
- `我的作品`：Tab `全部/待审核/已上架`（占位：功能即将上线）
- `我的钱包`：`卡密核销`（粘贴卡密）+ `邀请得福利`

## 9. 登录（login）

- Tab：`微信登录`（二维码 + `00:00:15 秒后二维码将刷新` + `未注册微信用户自动注册`）/ `邮箱·用户名登录` / `手机号登录`
- 注册赠送文案：`首次注册：赠送 30 基础模型积分、10 高级模型积分、5 专业绘画积分、5 Agent 积分额度`
- 底部：默认勾选同意《用户协议》《隐私政策》

## 10. 与 NVS 现有实现的差距清单（可执行）

| 能力 | SparkAI | NVS 现状 | 建议 |
|---|---|---|---|
| 模型广场筛选 | 类型+厂商+搜索 | 类型 Tab + 搜索 | 补「厂商」维度（`AiModel` 增 vendor 字段或复用 provider_hint） |
| 绘画模型选卡 | 卡片墙 + 一句定位 | 下拉框 | 改为卡片墙（`note` 作定位语，api_kind 作角标） |
| 绘画比例 | 1:1/9:16/2:3/3:4/4:3 | 3 档 size | 扩展为 5 档比例，映射到 MJ `--ar` / OpenAI size / Gemini 提示词 |
| 混图/换脸 | 有（换脸维护中） | 无 | 混图=参考图入参（MJ base64Array / gpt-image 参考图），二期 |
| 灵感广场 | 作品+提示词+复刻 | 提示词库（无作品流） | 用「我的绘画历史 + 一键复刻」近似，二期做公开流 |
| 视频广场 | 有 | 仅我的任务 | 二期（需审核与公开开关） |
| 视频分镜脚本 | 场景化提示词 | 单框提示词 | 提示词模板即可覆盖（视频类预设已加「空镜/人物/转场」） |
| Agent 市场分类+使用量 | 有 | 有智能体，无分类/使用量 | 低成本可补：`category` + `used_count` |
| 思维导图 | 大纲→导图 | 无 | 用 AI 生成 Markdown 大纲 + 前端 mermaid mindmap 渲染（Cherry 已带 mermaid） |
| 分品类额度 | 普通/旗舰/绘画/Agent 分账 | 单一代币池 + 按模型单价 | 保持单池（更简单）；如需分账，`TokenLedger` 已可按 type 扩展 |
| 登录方式 | 微信/邮箱/手机 | 微信/邮箱/手机 + 滑块 | 已对齐 |
| 注册赠送 | 分品类赠送 | 有免费额度（按日） | 已覆盖（平台免费额度 + 按人覆盖） |
