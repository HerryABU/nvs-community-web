## 二、对话视图关键交互

- 主操作：`开启新对话 Ctrl+K`（快捷键提示常驻）。
- 三个筛选维度叠加：
  1. 类型 Tab：`全部 / 对话 / 图像 / 视频 / 音频 / 我的`（注意有 **音频**，且「我的」= 我的收藏/订阅模型）；
  2. 厂商下拉：`全部厂商`；
  3. 搜索框：`搜索模型 / 描述`（模型名 + 描述双字段检索）。
- 模型卡片信息密度（每个卡片）：`名称（含 🔥最新/NEW 徽标）` + `单价（N 积分）` + `厂商` + `2-3 行能力描述`。
- 模型总量展示：`大模型广场 140`（总数徽标）。
- 会话侧栏：`对话历史 0`、`沉浸模式`（专注模式开关）。
- 空态：`试试这样问` + 3 条示例问题 + 一排智能体快捷入口（一屏可点即用）。
- 输入区 placeholder：`来说点什么吧...（Shift + Enter = 换行；Enter = 发送）`，支持 `file` 附件上传。

> 结论：智能体是「预设 system prompt + 首句引导」的轻量包装，重运营价值在于**分类陈列 + 一句话起手**，无需复杂工作流引擎。

## 四、模型陈列策略（可直接借鉴）

- 版本号写在名称里并统一前缀（`🔥最新` / `🎨最强` / `🎬`）拉点击；
- 卡片副标固定三段：`NEW 徽标` + `N 积分` + `厂商`；
- 描述统一 2 句话结构化：「定位 + 能力边界」，便于用户横向比较；
- 类型维度包含 **音频**，说明其模型池已覆盖 TTS/音乐（suno）。

## 五、对本项目（NVS 全 AI 台）的取舍

| SparkAI 做法 | NVS 采纳情况 |
|---|---|
| 左侧分区导航（对话/绘画/视频/智能体/会员） | ✅ 已用 Tab + 侧栏实现（对话/绘画/视频/智能体） |
| 模型广场多维度筛选（类型/厂商/搜索） | ✅ 采纳：模型带 `kind` 与厂商，前端按类型 Tab 过滤 + 搜索 |
| 模型卡片显示单价与能力描述 | ✅ 采纳：`price_call` + `Note` 直出 |
| 智能体市场（分类 + 一句话起手） | ✅ 已有 `AiAgent`（emoji/描述/问候语），将继续补分类 |
| 灵感广场（提示词广场） | ✅ 以「提示词库」实现（平台预设 + 用户自定义） |
| 自定义应用菜单（可挂外部） | ⏳ 未做（NVS 已有「扩展应用 /frames」体系，可后续对接） |
| 思维导图 | ⏳ 未做（可用 Cherry Mermaid + 大纲生成近似实现） |
| 音频模型（TTS/音乐） | ⏳ 未做（模型池已预留 kind 扩展位） |
| 沉浸模式 | ⏳ 未做（纯前端专注布局，成本低，可后续加） |
| `Ctrl+K` 新对话快捷键 | ✔ 待补（一行键盘监听） |
